Everything in *Instacalc Tutorial*, in one place. This page computes too:

```ic
notes = count(vaulttable("Instacalc Tutorial/**", file))
```

This folder has {notes} notes, and every number in them is worked out by the plugin as you read. Add a note and the count goes up.

(The pictures load from GitHub, so they need the network; the notes themselves do not.)
