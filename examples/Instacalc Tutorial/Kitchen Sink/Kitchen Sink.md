# Kitchen Sink

Every Instacalc feature in one note. Generated by `pnpm kitchen-sink` from the sources that define each feature; regenerate it, do not edit it.

See also [[Kitchen Sink - Functions]] (every builtin), [[Kitchen Sink - Chart edge cases]] (charts against awkward inputs) and [[Kitchen Sink.ic]] (the same rows, calc-first).

## Rows and prose

Every kind of row: prose, notes, comments, strings, headings, hidden helpers and sections.

### Prose, notes and comments

A bare sentence is prose and needs no marker.

```ic
Consecutive prose lines group together with no gap.
/// Narrative rows use **triple-slash** and take *markdown*, [links](https://instacalc.com) and `inline code`.
// A double-slash line is an author note, shown dimmed.
"a quoted row is a string value"
---
// Above: a divider drawn from three dashes.
```

### Named values and answers in a sentence

Rows compute top to bottom and a sentence can show any answer in braces.

```ic
price = 40
qty = 3
subtotal = price * qty
shipping = 12
total = subtotal + shipping
The order comes to {total}, or {total / qty} per item.
price * qty + shipping
```

### Explain the working

`explain` before a name or an expression keeps its answer and opens the Why working under the row: the formula, the values plugged in, the result.

```ic
watts = 60
hours = 5
kwh_price = 0.2
daily_cost = watts * hours / 1000 * kwh_price
explain daily_cost
explain watts * hours
```

### Hidden helpers

A leading underscore or the hidden decorator computes a row without showing it.

```ic
_fee_share = 0.08
tax = subtotal * _fee_share
handling = 2 // @hidden
grand total = total + tax + handling
```

## Tables and sheets

### A sheet


## Decorators

Every decorator the engine recognizes, each with its own summary and, where one exists, a live example.

### Emphasis & visibility

#### @hero

Shows the row as a large card.

```ic
revenue = $8,400
costs = $5,200
profit = revenue - costs // @hero @prefix($)
```

#### @nohero

Stops Instacalc from picking a result to feature as a large card. A row with @hero still shows as one.

```ic
price = $49
units = 100
total = price * units // @nohero @prefix($)
```

#### @accent

Highlights the row in the theme's accent color.

```ic
revenue = $8,400
costs = $5,200
profit = revenue - costs // @prefix($)
margin = profit / revenue * 100 // @accent @suffix(%) @label(Gross margin)
```

#### @advanced

Tucks the row behind a "more options" link at the end of its section.

```ic
price = $49
units = 1,200
revenue = price * units // @hero @prefix($)
tax_rate = 7% // @advanced
```

#### @hidden

Computes the row but never shows it. Good for in-between steps. With a condition, like @hide(discount = 0), it hides the row only while the condition is true.

```ic
cash = $500,000
burn = $45,000
runway = cash / burn // @hero @suffix(months)
tax_rate = 7% // @hidden
```

#### @show

Shows the row only while the condition is true, like @show(discount > 0). The row still computes, so other rows can use it.

```ic
has_discount = true // @toggle
discount = 15 // @show(has_discount) @suffix(%)
price = $100
final = price * (1 - (has_discount ? discount/100 : 0)) // @hero @prefix($)
```

#### @disabled

Dims the row and locks its control. With a condition, like @disabled(total > 100), it does that only while the condition is true.

```ic
use_coupon = false // @checkbox
coupon_code = "SAVE20" // @disabled(!use_coupon) @label(Coupon code)
base_price = $100 // @prefix($)
```

#### @enabled

Unlocks the row's control only while the condition is true. The reverse of @disabled.

```ic
enable_extra = false // @checkbox
extra_seats = 5 // @enabled(enable_extra) @label(Extra seats)
base_seats = 10 // @label(Base seats)
```

#### @readonly

Shows an input as a fixed value that readers can't edit.

```ic
list_price = $59 // @readonly @label(List price)
your_price = $49 // @label(Your price)
```

### Labels & units

#### @label

Replaces the row's name with your own words.

```ic
w = 72 // @label(Body weight) @suffix(kg)
```

#### @prefix

Adds text before the value, like @prefix($).

```ic
budget = 5000 // @prefix($) @label(Budget)
```

#### @suffix

Adds text after the value, like @suffix(months).

```ic
distance = 42 // @suffix(km)
pace = 5.5 // @suffix(/km) @label(Pace)
```

#### @icon

Shows a Lucide icon beside the row, like @icon(clock).

```ic
deadline = 14 // @suffix(days) @icon(clock)
budget = $5,000 // @icon(wallet)
```

#### @tooltip

Help text that appears when you hover the row.

```ic
margin = 38% // @tooltip(Revenue minus cost, divided by revenue) @label(Gross margin)
```

#### @note

Help text shown next to the row.

```ic
apr = 6.5% // @note(Compounded monthly) @label(Interest rate)
```

#### @explain

Adds a Why button that shows your explanation. Bare @explain shows one Instacalc writes for you.

```ic
a = 3
b = 4
c = sqrt(a^2 + b^2) // @hero @explain(Pythagoras: the hypotenuse of a right triangle)
```

#### @unit

Shows the row's result in a unit, like @unit(cm). A value that has a unit converts, and a plain number takes the unit.

```ic
dist = 5 km + 400 m // @unit(m) @label(Meters)
speed = 60 mph // @unit(kph) @label(Speed)
```

#### @decimals

Shows exactly this many decimal places, like @decimals(2). Only the display changes, not the value.

```ic
markup = 40 / 60 as percent // @decimals(1) @label(Markup)
per_person = 100 / 3 // @decimals(2) @prefix($)
```

#### @progress

Draws a progress bar for the number. The bar runs from 0 to 100 unless you give a range, like @progress(0, 500).

```ic
goal = 75% // @progress @label(Q3 Milestone)
quota = 35 // @progress(10, 50) @label(Active pipeline)
revenue = $850k // @hero @progress(0, 1000000) @prefix($)
```

#### @arrowdown

Runs an action when the Down arrow or S key is pressed.

```ic
depth = 5 // 0..10 @arrowdown(depth = max(0, depth - 1))
```

#### @arrowleft

Runs an action when the Left arrow or A key is pressed.

```ic
column = 3 // 0..6 @arrowleft(column = max(0, column - 1)) @arrowright(column = min(6, column + 1))
```

#### @arrowright

Runs an action when the Right arrow or D key is pressed.

```ic
lane = 1 // 0..3 @arrowright(lane = min(3, lane + 1))
```

#### @arrowup

Runs an action when the Up arrow or W key is pressed.

```ic
level = 5 // 0..10 @arrowup(level = min(10, level + 1)) @arrowdown(level = max(0, level - 1))
```

#### @art

Shows a built-in illustration beside the row, like @art(coin).

```ic
coins = 3 // @art(coin)
```

#### @check

Shows an error on the row when a condition fails, like @check(age >= 18, "Must be 18 or older").

```ic
age = 21 // @check(age >= 18, "Must be 18 or older")
```

#### @key

Runs an action when a key is pressed, like @key(Space, score = score + 1). Handy for games.

```ic
score = 0 // @key(Space, score = score + 1) @label(Press space)
```

#### @max

Sets the largest value an input accepts, like @max(100).

```ic
seats = 12 // @max(40)
```

#### @min

Sets the smallest value an input accepts, like @min(0).

```ic
guests = 8 // @min(1) @max(20)
```

#### @pivot

Summarizes a table as a pivot grid: one field down the side, one across the top, and a total in each cell.

```ic
sales = [{region: "East", quarter: "Q1", amt: 100}, {region: "West", quarter: "Q1", amt: 90}, {region: "East", quarter: "Q2", amt: 150}] // @pivot(region, quarter, amt, sum)
```

#### @placeholder

Sets the hint text shown in an empty input.

```ic
nickname = "" // @placeholder(e.g. Sam)
```

#### @rate

Fixes a currency exchange rate, like @rate(EUR, 1.08), so everyone who opens the calc gets the same answer.

```ic
trip = €500 in USD // @rate(EUR, 1.08)
```

#### @required

Marks an input as required and shows a message while it is empty.

```ic
email = "sam@example.com" // @required @placeholder(you@example.com)
```

#### @step

Sets how far a slider or stepper moves each time, like @step(5).

```ic
budget = 50 // 0..200 @step(5)
```

#### @warn

Shows a warning on the row when a condition fails. Unlike @check, it doesn't count as an error.

```ic
speed = 70 // @warn(speed <= 65, "Over the limit")
```

### Input controls

#### @color

Shows a color swatch with a picker. A quoted hex color, like "#3b82f6", gets one on its own.

```ic
brand = "#3b82f6" // @color @label(Brand Color)
accent = lighten(brand, 20) // @label(Light Accent)
```

#### @slider

Turns a number into a slider, like @slider(0, 100, 5). A range in the comment, like 1..100, works too.

```ic
budget = 5000 // @slider(1000, 20000, 500) @prefix($) @label(Monthly budget)
```

#### @stepper

Keeps minus and plus buttons on the number on every device, like @stepper(5).

```ic
kalid = 4 // @stepper @label(Kalid)
bid = $20 // @stepper(5) @label(Your bid)
```

#### @dropdown

Lets readers pick the value from a list.

```ic
price = 20 // @dropdown(10, 20, 40) @prefix($) @label(Plan price)
```

#### @toggle

Adds an on/off switch in front of an input. While it is off, the row's value is false. @toggle(off) starts it off.

```ic
steel_fiber = 110 // 10..110 by 10 @toggle(on) @suffix(%) @label(Steel Fiber)
```

#### @radio

Shows the choices as radio buttons. Readers pick one.

```ic
size = "M" // @radio(S, M, L) @label(Shirt size)
```

#### @buttons

Shows the choices as a row of buttons. Readers pick one.

```ic
tier = "Pro" // @buttons(Free, Pro, Max) @label(Tier)
```

#### @checkbox

Shows a yes or no value as a checkbox.

```ic
agree = false // @checkbox @label(I agree to the terms)
```

#### @checklist

Lets readers tick several options. The row's value is the total of the ticked items.

```ic
addons = 40 // @checklist(Analytics=15, Backup=25, Support=50) @prefix($)
base = 100 // @prefix($)
total = base + addons // @hero @prefix($)
```

#### @multiselect

Lets readers pick several options from a group of chips.

```ic
envs = "Production" // @multiselect(Dev, Staging, Production) @label(Active environments)
```

#### @combobox

A dropdown you can type into to narrow the choices.

```ic
country = "Canada" // @combobox(Canada, United_States, Germany, Japan) @label(Billing country)
```

#### @image-cards

Shows the choices as cards with pictures. Readers pick one. Needs image options, so it is best seen in a full calc.

#### @date

Picks the value from a calendar.

```ic
start = 2026-01-15 // @date @label(Start date)
```

#### @time

Picks the value with a time picker.

```ic
backup window = "03:00" // @time
```

#### @datetime

Picks a date and a time together. Put it on a row that holds a date and time.

#### @range

Turns a number into a slider. The same as @slider.

```ic
zoom = 100 // @range(50, 200, 10) @suffix(%) @label(Zoom)
```

#### @drag

In a live-prose embed on your own page, lets readers drag a number in the text to change it. Works only in the ic.js live-prose embed. Inside a calc it does nothing. See the Sharing guide.

#### @chips

Turns the value into a row of pill buttons for switching between options.

```ic
topic = "all" // @chips(["all", "money", "science"])
```

#### @clamp

Keeps an input inside its range. A value past either end snaps back to it.

```ic
headcount = 24 // 1..100 @clamp(1, 100)
```

#### @pills

Turns the value into a row of pill buttons for switching between options.

```ic
size = "M" // @pills(["S", "M", "L"])
```

#### @search

Turns the value into a search box. Results update as readers type.

```ic
query = "tea" // @search("Search drinks")
```

### Showing the math

#### @formula

Shows the formula behind the result, as you typed it. On a heading, it shows the formula for every row in that section.

```ic
# Pythagoras
a = 3
b = 4
c = sqrt(a^2 + b^2) // @hero @formula
```

#### @latex

Used with @formula: typesets the formula as math instead of showing the text you typed.

```ic
principal = $10,000
rate = 6%
years = 10
balance = principal * (1 + rate) ^ years // @hero @prefix($) @formula @latex
```

#### @debug

Shows a table of how Instacalc worked out the row. Only you see it, in Calc view. Present mode and embeds leave it out. Calc view only. Present mode and embeds leave it out, so this preview cannot show it.

### Sections & layout

#### @section

Starts a new section with this title. A line that starts with # does the same.

```ic
# Inputs
amount = $400,000
rate = 7%
# Result
total = amount * (1 + rate) // @hero @prefix($)
```

#### @collapsed

Starts the section closed. Readers click the heading to open it.

```ic
# Summary
total = $466 // @hero @prefix($)
# Details @collapsed
compute = $364 // @prefix($)
storage = $57 // @prefix($)
egress = $45 // @prefix($)
```

#### @bars

Draws a faint bar behind each value in the section, sized against the largest, so the big items stand out.

```ic
# Monthly spend @bars
rent = $1,800
groceries = $620
transit = $140
fun = $360
```

#### @carousel

Turns consecutive sections into slides with next and previous buttons.

```ic
# Slide 1: Welcome // @slides
revenue = $850k // @hero @progress(0, 1000000) @prefix($)
# Slide 2: Metrics // @slides
growth = 35% // @hero @progress
```

#### @density

Sets how tightly a section's rows are packed, like @density(compact).

```ic
# Controls @density(compact)
a = 1
b = 2
c = 3
d = 4
```

#### @skin

Gives a section an experimental look, like @skin(spec-sheet). Beta: the name and the looks may change. Best seen on a full calc.

#### @as

Picks how a section shows in Dashboard view: as a calc, text, graph, present page, table, or note. Takes effect in Dashboard view. Open a calc as a dashboard to see it.

#### @rownums

Shows row numbers for the section in Dashboard view. Dashboard view only.

#### @cols

Names a table's columns, in order, like @cols(Item, Amount).

```ic
items = [{name: "Rent", amt: 1800}, {name: "Food", amt: 600}] // @sheet @cols(Item, Amount)
```

#### @controls

Puts the section in the inputs column when the page shows two columns.

```ic
## Inputs @controls
loan = $300,000
## Result @results
payment = loan / 360
```

#### @results

Puts the section in the results column when the page shows two columns.

```ic
## Inputs again @controls
hours = 40
## Pay @results
pay = hours * $25
```

#### @dashboard

Opens the calc in Dashboard view. Applies to the whole calc. It changes which view opens first, not how any row looks.

#### @half

Makes the row span half the width. In Present mode, pick a row width from the Design panel to try it.

#### @third

Makes the row span one third of the width. In Present mode, pick a row width from the Design panel to try it.

#### @wide

Makes the row span the full width. In Present mode, pick a row width from the Design panel to try it.

#### @col2

An older two-column setting for a section, kept so old calcs still open. Use @layout(grid) instead. An older layout setting.

#### @span

An older width setting: @span(full) makes the row span the full width. An older layout setting.

#### @split

An older way to put inputs on one side and results on the other. Use @layout(split) instead. An older layout setting. The Split layout in the Present settings does the same.

#### @card

Draws the section inside a card. The same as @panel.

```ic
## Inside a card @card
card value = 7
```

#### @tab

Shows the section as a tab. Consecutive sections that use @tab become one set of tabs. In Present mode, turn it on from a heading's menu.

#### @layout

Arranges a section's rows, like @layout(grid) or @layout(split). On the title line, it sets the layout for the whole calc.

```ic
## Three across @layout(grid)
red = 255
green = 128
blue = 64
```

#### @width

On a section header, sets that panel's width in Dashboard view: @width(full|half|third), default half. Has no effect in Present view. On a section header. Sets that panel's width in Dashboard view (defaults to half). No effect in Present view.

#### @bento

Arranges the items in a row as dashboard tiles on a 12-column grid.

```ic
tiles = [kpi(1250, "users"), gauge(73), progress(420, 1000)] // @bento
```

#### @calc

Shows a link to another calc as a card with a live preview. No standalone example.

#### @float

Pins the section to the top or bottom of the screen, so it stays in view while readers scroll. Use @float(top) or @float(bottom). No standalone example.

#### @grid

Arranges the items in a row, like a list of shapes, in a grid.

```ic
shapes = [kpi(1, "one"), kpi(2, "two"), kpi(3, "three"), kpi(4, "four")] // @grid
```

#### @hstack

Places the items in a row side by side.

```ic
side by side = [kpi(12, "open"), kpi(30, "closed")] // @hstack
```

#### @panel

Draws the section inside a raised card with a rounded border.

```ic
## Inside a panel @panel
panel value = 42
```

#### @vstack

Stacks the items in a row on top of each other.

```ic
stacked = [kpi(12, "open"), kpi(30, "closed")] // @vstack
```

### Data tables

#### @col

Formats one column of a table, like @col(Amount as money), or adds a computed one, like @col(Total = qty * price as money).

```ic
timesheet = [{task: "Design", hours: 8, wage: 20}, {task: "Build", hours: 12, wage: 20}] // @sheet @col(Task, tooltip: Active project phase) @col(Hours to 1 decimal place) @col(Wage as money) @col(Total = hours * wage as money)
```

#### @sheet

Shows a list of records as an editable table. Readers can edit cells, add or delete rows, and sort by clicking a column header.

```ic
items = [{name: "Rent", amt: 1800}, {name: "Food", amt: 600}, {name: "Transit", amt: 120}] // @sheet @cols(Item, Amount) @totals
```

#### @sort

Sets a table's starting sort, like @sort(amount desc). Clicking a column header updates it. The data itself doesn't change.

```ic
items = [{name: "Rent", amt: 1800}, {name: "Food", amt: 600}, {name: "Transit", amt: 120}] // @sheet @cols(Item, Amount) @sort(amt desc)
```

#### @totals

Adds a footer to a table with the total of each number column.

```ic
items = [{name: "Rent", amt: 1800}, {name: "Food", amt: 600}, {name: "Transit", amt: 120}] // @sheet @cols(Item, Amount) @totals
```

#### @filter

Shows only the table rows that match, like @filter(amount > 500). The data itself doesn't change.

```ic
items = [{name: "Rent", amt: 1800}, {name: "Food", amt: 600}, {name: "Transit", amt: 120}] // @sheet @cols(Item, Amount) @filter(amt > 500)
```

#### @summary

Adds your own footer rows to a table, built from a list you compute in other rows. Reads a list you build with normal calc rows, so it is best seen in a full calc.
