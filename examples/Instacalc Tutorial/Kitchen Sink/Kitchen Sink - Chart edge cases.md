# Kitchen Sink - Chart edge cases

The inputs charts-audit judges every chart against, drawn. A row marked "expect an empty state" should show a readable empty state or error, never a drawing. Generated by `pnpm kitchen-sink` from the sources that define each feature; regenerate it, do not edit it.

## Chart edge cases

Charts against awkward inputs: no data, one value, zeros, negatives, NaN, names that mean nothing, huge and tiny.
