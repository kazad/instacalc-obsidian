## A weekend away

Plain arithmetic, no syntax:

420 + 380

Name a value to use it later. Names can have spaces:

flights = 420 + 380  
hotel = 3 * 145  
food = 260  
total = flights + hotel + food

A percentage of something:

10% of total

Split three ways. Anything after `//` is a comment:

total / 3 // each  
round(total / 3) // each, rounded
